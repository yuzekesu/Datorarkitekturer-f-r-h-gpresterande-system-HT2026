# Q2.6 What is the difference between an FMA and a MUL instruction? How does the gray scale formula become one multiplication and two multiply-adds?
Fused Multiply-Add means doing multiplication and addition at the same time. The minimal step for one channel is:
```c
int r = R_VALUE.
r *= weight_r;
r += weight_g * g;
r += weight_b * b;
```
which is one multiplication plus two fused multiply-add.
